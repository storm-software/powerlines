# License

The Powerlines CLI package (`@powerlines/cli`) uses the **Apache License 2.0**. The SPDX identifier in every inspected source header and in `packages/devkit/cli/package.json` is `Apache-2.0`.

The repository root holds the full license text:

- File: `LICENSE` in the workspace root.
- Homepage: [Powerlines project](https://stormsoftware.com/projects/powerlines).
- Licensing page: `https://stormsoftware.com/licenses/projects/powerlines` (cited in every source header).

## What this means in practice

- You may use the CLI for commercial and private purposes.
- You may edit and distribute it under the license terms.
- You must preserve license and attribution notices.
