# Install the content-collections plugin

The `@powerlines/plugin-content-collections` package (v0.1.678) generate project code using Content Collections.

```sh
npm install @powerlines/plugin-content-collections
# pnpm add @powerlines/plugin-content-collections
# yarn add @powerlines/plugin-content-collections
```

Also install `@content-collections/core >= 0.12.3`.

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
