# Install the asyncapi plugin

The `@powerlines/plugin-asyncapi` package (v0.1.682) generate project code from AsyncAPI specifications.

```sh
npm install @powerlines/plugin-asyncapi
# pnpm add @powerlines/plugin-asyncapi
# yarn add @powerlines/plugin-asyncapi
```

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
