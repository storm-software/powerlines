# Install the deepkit plugin

The `@powerlines/plugin-deepkit` package (v0.11.560) add Deepkit runtime-type transformers to the TypeScript build.

```sh
npm install @powerlines/plugin-deepkit
# pnpm add @powerlines/plugin-deepkit
# yarn add @powerlines/plugin-deepkit
```

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
