# Install the crypto plugin

The `@powerlines/plugin-crypto` package (v0.10.734) add a `crypto` builtin module with encryption helpers.

```sh
npm install @powerlines/plugin-crypto
# pnpm add @powerlines/plugin-crypto
# yarn add @powerlines/plugin-crypto
```

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
