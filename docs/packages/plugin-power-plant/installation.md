# Install @powerlines/plugin-power-plant

Generates project code with the Power Plant engine.

## Install the package

```sh
npm install @powerlines/plugin-power-plant
```

```sh
pnpm add @powerlines/plugin-power-plant
```

```sh
yarn add @powerlines/plugin-power-plant
```

## Peer dependencies

No peer dependencies are declared in `package.json`.

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
