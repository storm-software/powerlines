# Install the graphql plugin

The `@powerlines/plugin-graphql` package (v0.1.679) generate project code from GraphQL schemas.

```sh
npm install @powerlines/plugin-graphql
# pnpm add @powerlines/plugin-graphql
# yarn add @powerlines/plugin-graphql
```

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
