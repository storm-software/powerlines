# Install the env plugin

The `@powerlines/plugin-env` package (v0.16.425) inject static `.env` configuration values so they are accessible at runtime.

```sh
npm install @powerlines/plugin-env
# pnpm add @powerlines/plugin-env
# yarn add @powerlines/plugin-env
```

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
