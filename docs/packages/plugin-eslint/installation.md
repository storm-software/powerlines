# Install the eslint plugin

The `@powerlines/plugin-eslint` package (v0.8.682) run ESLint on the codebase.

```sh
npm install @powerlines/plugin-eslint
# pnpm add @powerlines/plugin-eslint
# yarn add @powerlines/plugin-eslint
```

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
