# Install @powerlines/plugin-rollup

Bundles the project with Rollup through Powerlines.

## Install the package

```sh
npm install @powerlines/plugin-rollup
```

```sh
pnpm add @powerlines/plugin-rollup
```

```sh
yarn add @powerlines/plugin-rollup
```

## Peer dependencies

Install these alongside the plugin:

```sh
npm install rollup (>=4.46.4)
```

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
