# Install the hey-api plugin

The `@powerlines/plugin-hey-api` package (v0.1.632) generate project code using Hey API.

```sh
npm install @powerlines/plugin-hey-api
# pnpm add @powerlines/plugin-hey-api
# yarn add @powerlines/plugin-hey-api
```

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
