# Install @powerlines/plugin-oxc-transform

Transforms project code with the Oxc Transformer.

## Install the package

```sh
npm install @powerlines/plugin-oxc-transform
```

```sh
pnpm add @powerlines/plugin-oxc-transform
```

```sh
yarn add @powerlines/plugin-oxc-transform
```

## Peer dependencies

No peer dependencies are declared in `package.json`.

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
