# Install @powerlines/plugin-rolldown

Bundles the project with Rolldown through Powerlines.

## Install the package

```sh
npm install @powerlines/plugin-rolldown
```

```sh
pnpm add @powerlines/plugin-rolldown
```

```sh
yarn add @powerlines/plugin-rolldown
```

## Peer dependencies

Install these alongside the plugin:

```sh
npm install rolldown (>=1.0.1 <2.0.0)
```

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
