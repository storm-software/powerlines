# Configure the alloy plugin

Set options on the plugin call. They land under `config.alloy` in the resolved Powerlines config.

| Option | Type | Default | Notes |
| --- | --- | --- | --- |
| `template` | string | — | Alloy template entry used for code generation. |
| `outputPath` | string | — | Directory for generated output. |
| PrintTreeOptions fields | various | upstream defaults | Formatting options passed to the Alloy printer. |
