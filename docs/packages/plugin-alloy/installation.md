# Install the alloy plugin

The `@powerlines/plugin-alloy` package (v0.26.314) generate project code using Alloy JS via Power Plant.

```sh
npm install @powerlines/plugin-alloy
# pnpm add @powerlines/plugin-alloy
# yarn add @powerlines/plugin-alloy
```

Also install `@alloy-js/babel-preset >= 0.3.0`.

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
