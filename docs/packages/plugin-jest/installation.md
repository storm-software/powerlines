# Install @powerlines/plugin-jest

Runs Jest tests through Powerlines with shared transform settings.

## Install the package

```sh
npm install @powerlines/plugin-jest
```

```sh
pnpm add @powerlines/plugin-jest
```

```sh
yarn add @powerlines/plugin-jest
```

## Peer dependencies

No peer dependencies are declared in `package.json`.

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
