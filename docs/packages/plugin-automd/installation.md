# Install the automd plugin

The `@powerlines/plugin-automd` package (v0.1.678) maintain project Markdown files using AutoMD generators.

```sh
npm install @powerlines/plugin-automd
# pnpm add @powerlines/plugin-automd
# yarn add @powerlines/plugin-automd
```

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
