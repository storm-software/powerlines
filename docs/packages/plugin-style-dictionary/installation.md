# Install the Style Dictionary plugin

Add the package to your project.

```bash
pnpm add @powerlines/plugin-style-dictionary
```

<details>
<summary>Using npm</summary>

```bash
npm install @powerlines/plugin-style-dictionary
```

</details>

<details>
<summary>Using yarn</summary>

```bash
yarn add @powerlines/plugin-style-dictionary
```

</details>

## Requirements

- The plugin has no peer dependencies.
- The plugin registers itself through the `plugins` array in `powerlines.config.ts`. No extra setup is needed.
