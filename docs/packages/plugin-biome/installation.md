# Install the biome plugin

The `@powerlines/plugin-biome` package (v0.2.684) lint the codebase with Biome.

```sh
npm install @powerlines/plugin-biome
# pnpm add @powerlines/plugin-biome
# yarn add @powerlines/plugin-biome
```

Also install `@biomejs/biome >= 2.0.0`.

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
