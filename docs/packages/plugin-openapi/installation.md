# Install @powerlines/plugin-openapi

Generates project code from OpenAPI specifications.

## Install the package

```sh
npm install @powerlines/plugin-openapi
```

```sh
pnpm add @powerlines/plugin-openapi
```

```sh
yarn add @powerlines/plugin-openapi
```

## Peer dependencies

No peer dependencies are declared in `package.json`.

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
