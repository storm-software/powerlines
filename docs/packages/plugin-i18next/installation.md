# Install the i18next plugin

The `@powerlines/plugin-i18next` package (v0.1.575) use i18next for internationalization.

```sh
npm install @powerlines/plugin-i18next
# pnpm add @powerlines/plugin-i18next
# yarn add @powerlines/plugin-i18next
```

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
