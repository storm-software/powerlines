# Install @powerlines/plugin-nitro

Builds and serves a server application on Nitro.

## Install the package

```sh
npm install @powerlines/plugin-nitro
```

```sh
pnpm add @powerlines/plugin-nitro
```

```sh
yarn add @powerlines/plugin-nitro
```

## Peer dependencies

No peer dependencies are declared in `package.json`.

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
