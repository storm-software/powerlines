# Install @powerlines/plugin-react

Builds a React application with compiler and refresh support.

## Install the package

```sh
npm install @powerlines/plugin-react
```

```sh
pnpm add @powerlines/plugin-react
```

```sh
yarn add @powerlines/plugin-react
```

## Peer dependencies

Install these alongside the plugin:

```sh
npm install react (>=19.2.0), react-dom (>=19.2.0)
```

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
