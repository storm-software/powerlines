# Install @powerlines/plugin-oxlint

Runs Oxlint on the codebase inside the Powerlines lint process.

## Install the package

```sh
npm install @powerlines/plugin-oxlint
```

```sh
pnpm add @powerlines/plugin-oxlint
```

```sh
yarn add @powerlines/plugin-oxlint
```

## Peer dependencies

No peer dependencies are declared in `package.json`.

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
