# Install @powerlines/plugin-prisma

Generates project code and a Prisma client from a Prisma schema (PSL).

## Install the package

```sh
npm install @powerlines/plugin-prisma
```

```sh
pnpm add @powerlines/plugin-prisma
```

```sh
yarn add @powerlines/plugin-prisma
```

## Peer dependencies

No peer dependencies are declared in `package.json`.

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
