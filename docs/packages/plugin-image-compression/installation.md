# Install @powerlines/plugin-image-compression

Optimizes project images with Sharp and SVGO during the build.

## Install the package

```sh
npm install @powerlines/plugin-image-compression
```

```sh
pnpm add @powerlines/plugin-image-compression
```

```sh
yarn add @powerlines/plugin-image-compression
```

## Peer dependencies

No peer dependencies are declared in `package.json`.

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
