# Install @powerlines/plugin-open-feature

Manages OpenFeature feature flags at runtime.

## Install the package

```sh
npm install @powerlines/plugin-open-feature
```

```sh
pnpm add @powerlines/plugin-open-feature
```

```sh
yarn add @powerlines/plugin-open-feature
```

## Peer dependencies

No peer dependencies are declared in `package.json`.

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
