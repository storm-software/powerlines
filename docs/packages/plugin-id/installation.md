# Install the id plugin

The `@powerlines/plugin-id` package (v0.9.687) provide unique identifier generation at runtime by adding the `id` builtin module.

```sh
npm install @powerlines/plugin-id
# pnpm add @powerlines/plugin-id
# yarn add @powerlines/plugin-id
```

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
