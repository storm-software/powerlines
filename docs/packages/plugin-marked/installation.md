# Install @powerlines/plugin-marked

Compiles Markdown to HTML with Marked during the prepare task.

## Install the package

```sh
npm install @powerlines/plugin-marked
```

```sh
pnpm add @powerlines/plugin-marked
```

```sh
yarn add @powerlines/plugin-marked
```

## Peer dependencies

Install these alongside the plugin:

```sh
npm install marked (>=17.0.4)
```

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
