# Install the esbuild plugin

The `@powerlines/plugin-esbuild` package (v0.13.671) build projects using esbuild.

```sh
npm install @powerlines/plugin-esbuild
# pnpm add @powerlines/plugin-esbuild
# yarn add @powerlines/plugin-esbuild
```

Also install `esbuild >= 0.27.3`.

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
