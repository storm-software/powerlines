# Install the date plugin

The `@powerlines/plugin-date` package (v0.12.769) add a `date` builtin module backed by a date library.

```sh
npm install @powerlines/plugin-date
# pnpm add @powerlines/plugin-date
# yarn add @powerlines/plugin-date
```

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
