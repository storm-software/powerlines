# Install the capnp plugin

The `@powerlines/plugin-capnp` package (v0.1.681) generate project code from Cap'n Proto schemas.

```sh
npm install @powerlines/plugin-capnp
# pnpm add @powerlines/plugin-capnp
# yarn add @powerlines/plugin-capnp
```

The package ships ESM and CJS builds with types. Import the plugin factory from the package root.
