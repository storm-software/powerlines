# Install @powerlines/plugin-pulumi

Deploys infrastructure with Pulumi automation.

## Install the package

```sh
npm install @powerlines/plugin-pulumi
```

```sh
pnpm add @powerlines/plugin-pulumi
```

```sh
yarn add @powerlines/plugin-pulumi
```

## Peer dependencies

No peer dependencies are declared in `package.json`.

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
