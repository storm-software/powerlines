# Install @powerlines/plugin-nodejs

Builds a Node.js application with shared env and Babel handling.

## Install the package

```sh
npm install @powerlines/plugin-nodejs
```

```sh
pnpm add @powerlines/plugin-nodejs
```

```sh
yarn add @powerlines/plugin-nodejs
```

## Peer dependencies

No peer dependencies are declared in `package.json`.

> [!NOTE]
> Powerlines packages are versioned independently. Pin the plugin version to match your `powerlines` core version.
